# SPARTAN READER

英文を貼り付け、かたまりごとに指定速度で表示する読書トレーニングです。
通常の英文・改行で区切った英文・日本語訳付きJSONを読み込めます。

## 開発

Node.js 22.6以上とpnpmを使用します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

```sh
pnpm typecheck
pnpm test
pnpm build
```

本番用の静的ファイルは `dist/` に生成されます。CSSはビルド時に生成するため、Tailwind CDNへの接続は不要です。

## 教材

通常英文の分割はローカルの簡易ルールです。AIによる自動翻訳は行いません。
分割と日本語訳を指定したい場合は次のJSON配列を入力してください。

```json
[
  { "en": "Life is short.", "jp": "人生は短い。", "speaker": null },
  { "en": "Keep moving forward.", "jp": "前に進もう。", "speaker": null }
]
```

入力画面の「日本語訳付きで読むには」から、外部AIへ渡す依頼文をコピーできます。
JSONの形式が不正な場合や英文が欠けている場合は、教材の一部を省略せずエラーを表示します。
テキストファイルは `.txt` / `.json`、2MBまで対応します。

## 読書と保存

- 開始ボタンを押すと2秒後に再生。前後移動と一時停止はタッチでもキーボードでも操作できます。
- 設定画面を開く・タブを非表示にする操作で一時停止します。
- 日本語訳の待ち時間も一時停止し、訳をOFFにすると表示時間には加算しません。
- 読了目安は表示速度と訳の待ち時間から算出します。実際に理解して読めた時間や能力向上を計測するものではありません。
- 「入力へ」は英文を保持。「ここで終了」は入力欄を空にして入口に戻ります。
- 履歴は既存の `spartan_reader_history` を引き継ぎ、このブラウザ内に保存します。通常の履歴は15件、お気に入りはその件数制限から除外します。同期機能はありません。
- 保存失敗は画面に表示。読み込めない既存の履歴データは上書きしません。

確認済み：390px・320px幅の英文表示、デスクトップ表示、入力保持、JSONエラー、再生・一時停止・前後移動、読了、復習、表示単位切り替え、訳の待ち時間。
実機iOS Safariや全ブラウザでの網羅確認はしていません。
